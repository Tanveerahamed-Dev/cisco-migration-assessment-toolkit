## Raw form boundary (R20)

The new request spelling is vlan_zones: {raw_rows: [{zone, vids}]}. A bare array remains malformed.
The browser trims values and preserves each nonblank row using split/filter/map/truthiness only.
It never counts, groups, converts VID numbers, deduplicates, applies ranges or overwrites zone keys.
The engine shares one ASCII decimal/range parser for legacy maps and raw rows, rejects duplicate
VIDs including aliases and duplicate trimmed zone rows, and stores the same string-keyed map as before.

For reopen, engine saved_plan_vlan_form_rows publishes grouped editor rows as the primitive response
field vlan_form_rows. It is computed outside Store._lock, not stored in the immutable envelope and
not revision/digest authority. It prevents a multi-VID canonical zone from being split into duplicate
raw zone rows on the next save. GET/save/select use the same pre-serialized response assembler.

The client displays the persisted design_nrfu.note and item list with no empty predicate, recount or
client no-rows sentence. The note already includes zero from the engine.

## Response, storage and lock boundaries

The new logic remains interface-role backend code: the DTOs, runtime catalogue copied view, facade,
pre-serialized response assembler, small identity finalizer, internal historical event input and
Store lock shield. None declares an engine role or computes a network fact. These families must be
listed in the S1g proposal even when the detector emits no tuple. Generic shape/metadata/reentry work
does not acquire an automatic admission category.

The actual event ID is allocated under the existing BEGIN IMMEDIATE; unrelated snapshots do not
produce a predicted-ID conflict. Default-mode callers are current GET/reopen, select preparation
using a genuine digest-matched historical event, and export. Only new-revision preparation passes
absent mode; it refuses any selection_id key and is never selected from record content or wire data.
List retains anchored byte/history checks without semantic per-revision scans.

Locked full-source hash counts under measurement: save 2, select 2 (existing route bound read plus
unchanged transaction state owner); current GET 1, list 1 and export before/after contexts 2.
The bounded scalar marker/count pre-read adds zero full-source hashes and no envelope decode.
The synthetic measurement covers it explicitly. The reentry guard preserves nonblocking False
probes, timeout/argument errors, native foreign release and context-manager behavior. A blocking
same-thread finalizer reentry refuses promptly and publication rolls back.
